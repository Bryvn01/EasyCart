## Services Overview

### Service Names vs Render URLs

**Understanding Render Service Naming:**
- Service name in `render.yaml`: `easycart-backend`
- Actual Render URL suffix: `0u8r` (assigned by Render)
- Full URL: `https://easycart-backend-0u8r.onrender.com`

**Note:** The `0u8r` suffix is assigned by Render and may differ from the service name defined in render.yaml.

- [ ] **Verify easycart-backend-0u8r exists and is on main branch**
  - Login: https://render.com/dashboard
  - Branch: main
  - Auto-deploy: Enabled
  - Root directory: backend

- [ ] **Locate easycart-j6ue service (if exists)**
  - Check current branch
  - Document all environment variables

- [ ] **Sync environment variables from j6ue to 0u8r**
  - MONGODB_URI
  - CLOUDINARY_URL
  - JWT_SECRET
  - Any custom variables

- [ ] **Redeploy easycart-backend-0u8r**

## Environment Variables Required

Copy these from easycart-j6ue (if they exist) to easycart-backend-0u8r:

```bash
# Critical - Must have
MONGODB_URI=mongodb+srv://...
SECRET_KEY=<auto-generated>
JWT_SECRET=<auto-generated>
DEBUG=False
ALLOWED_HOSTS=easycart-backend-0u8r.onrender.com,.onrender.com

# Recommended
CLOUDINARY_URL=cloudinary://api_key:api_secret@cloud_name

# Django Configuration
DJANGO_SETTINGS_MODULE=ecommerce.settings
WEB_CONCURRENCY=2
PYTHON_VERSION=3.11.0
```

## Troubleshooting

### "Service not responding"
- Check Render logs for errors
- Verify environment variables are set
- Check MONGODB_URI is correct
- Redeploy service

### "CORS error in frontend"
- Verify CORS_ALLOWED_ORIGINS includes frontend URL
- Check frontend uses correct backend URL
- Redeploy backend after CORS fix

### "Database connection error"
- Verify MONGODB_URI is set correctly
- Check MongoDB Atlas allows Render IPs (0.0.0.0/0)
- Test connection from Render shell

### "Environment variable missing"
- Compare variables between j6ue and 0u8r
- Add missing variables to 0u8r
- Redeploy after adding variables
